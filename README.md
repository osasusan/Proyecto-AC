# MANGA APPLE CODING ACADEMY

It is an application for iOS.
It is an app that collects manga through My Anime List.
You cannot read them, you can only see a description, the synopsis, author, and other information. 

## Software
- Xcode 15.3
- Swift 5.10

## Libraries
- SwiftUI
## Minimum Deplyments
- ios 17.4
